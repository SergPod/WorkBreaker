# WorkBreaker — напоминание о перерывах

Мини-приложение в стиле Stretchly: живёт в системном трее и напоминает
делать перерывы — короткие (mini) и длинные (long). Звуков и окон настроек
"в лоб" нет: всё управление — через меню значка в трее.

## Запуск

1. Запустите `WorkBreaker.exe`. На экране ничего не появится — приложение
   работает только как значок в трее (чашка/иконка WorkBreaker).
2. Одновременно может работать **только один экземпляр**: повторный запуск
   покажет сообщение "WorkBreaker is already running in the system tray".
3. Настройки хранятся в INI-файле в каталоге конфигурации приложения
   (`WorkBreaker.ini`) и сохраняются автоматически.

## Виды перерывов

| Перерыв | По умолчанию | Когда наступает |
|---|---|---|
| Mini (короткий) | 20 сек каждые 10 мин | После каждого интервала mini-перерывов |
| Long (длинный) | 5 мин | После N mini-перерывов подряд (по умолчанию — 2) |

## Окно перерыва

При наступлении перерыва по центру появляется безрамочное окно поверх всех
окон:

- **MINI BREAK / LONG BREAK** — какой перерыв идёт;
- большие цифры **мм:сс** — сколько осталось;
- **Postpone break** — отложить перерыв; после паузы окно появится снова,
  и его можно будет отложить ещё (сколько угодно раз);
- **Skip break** — пропустить перерыв сейчас.

Горячие клавиши окна:

- **Esc** — завершить перерыв (то же, что Skip);
- **Alt+F4** — то же самое.

Окно всегда остаётся поверх остальных: если вы переключитесь в другую
программу, оно снова поднимется наверх.

## Меню значка в трее

Правый клик по значку (значок настроен показывать меню автоматически):

| Пункт | Действие |
|---|---|
| **New mini break** | Начать короткий перерыв сейчас |
| **New long break** | Начать длинный перерыв сейчас |
| **Skip current break** | Завершить текущий перерыв (активен только во время перерыва) |
| **Postpone current break** | Отложить текущий перерыв (активен только во время перерыва) |
| **Reset break counter** | Сбросить счётчик mini-перерывов и начать отсчёт заново |
| **Pause breaks → …** | Приостановить все перерывы: на 30 минут / 1 час / 2 часа / до возобновления |
| **Resume breaks** | Возобновить перерывы (появляется вместо "Pause", когда пауза активна) |
| **Settings** | Открыть окно настроек |
| **Quit** | Выйти из программы |

Подсказка значка (наведите курсор и подождите) показывает текущий статус:
`next break in mm:ss`, `break mm:ss` или `paused`.

## Настройки (пункт Settings)

Все величины задаются в окне настроек, применяются кнопкой **OK**:

- **Mini break enabled** — включать короткие перерывы;
- **Mini break interval** — интервал между короткими перерывами, минут;
- **Mini break duration** — длительность короткого перерыва, секунд;
- **Long break enabled** — включать длинные перерывы;
- **Long break after N mini breaks** — через сколько коротких перерывов
  давать длинный;
- **Long break duration** — длительность длинного перерыва, минут.

После изменения настроек отсчёт до следующего перерыва начинается заново.

## Отложенные перерывы (Postpone)

- "Postpone" доступен каждый раз, когда показано окно перерыва: после
  отложенной паузы окно появляется снова и его можно отложить ещё —
  сколько угодно раз.
- После откладывания программа ждёт паузу (по умолчанию 2 мин для mini,
  5 мин для long), а затем снова показывает окно того же перерыва.
- Пока идёт отложенный отсчёт, пункты "New mini/long break" в меню
  заблокированы — сначала дождитесь повторного окна или нажмите Skip.

## Пауза и "отсутствие пользователя"

- **Pause breaks** полностью останавливает таймер; пауза не сохраняется
  после перезапуска программы (при старте перерывы всегда активны).
- **IdleLimit** — если вы не трогали клавиатуру/мышь дольше заданного
  порога (настраивается в Settings, по умолчанию **5 минут**), отсчёт
  до следующего перерыва сбрасывается — программа «понимает», что вы
  отошли, и не дёргает вас.

## Частые вопросы

**Окно перерыва не появилось.**
Проверьте, не запущен ли второй экземпляр (он не стартует). Если окно
"пропало" за другими — нажмите Alt+Tab или кликните по значку: окно
всегда topmost и поднимется наверх при следующем тике.

**Как полностью остановить перерывы надолго?**
Pause breaks → Until resumed, а затем Resume breaks из того же меню.
Либо Quit — после перезапуска программа стартует с активными перерывами.

**Где файл настроек?**
`WorkBreaker.ini` в каталоге конфигурации пользователя (для Windows:
`%APPDATA%\WorkBreacker\`). Можно редактировать вручную при выключенной программе.
